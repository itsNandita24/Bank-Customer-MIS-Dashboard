# 📊 Bank Customer MIS Dashboard

## 📌 Project Overview
An interactive Bank Customer MIS Dashboard created using Microsoft Excel to analyze customer banking data and provide business insights.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Analysis
- Interactive Dashboard

## 📈 Key KPIs
- Total Customers: 2,003
- Total Balance
- Average Balance
- Highest Balance
- Lowest Balance

## 📊 Dashboard Analysis
- Region-wise Bank Distribution
- Bank Balance by Region
- Gender-wise Bank Balance
- Gender-wise Bank Balance Comparison
- Balance Trend
- Job Classification Analysis

## 🎯 Key Features
- Interactive Region slicer
- Gender slicer
- Job Classification slicer
- Dynamic charts
- KPI cards
- Interactive filtering
